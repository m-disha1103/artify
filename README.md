Artify 
Artify is an Android application inspired by tools like Canva, designed to help users create simple and visually appealing designs directly on their mobile devices. It provides an easy-to-use interface for editing, customizing, and creating graphics.

> About the project
Artify is a beginner-friendly design tool that allows users to:
1) Create basic designs
2) Work with images and layouts
3) Explore creativity without complex tools
The goal of this project is to build a lightweight and simple graphic design experience on Android.

> features
🖼️ Image Editing
* Add and display images
* Customize visuals
🎨 Design Creation
* Create simple layouts
* Arrange elements on screen
✍️ Text Support
* Add text to designs
* Basic styling options
📱 User-Friendly UI
* Clean and minimal interface
* Easy navigation
